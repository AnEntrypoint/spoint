## (1) CPU HEIGHT SAMPLE DETERMINISM

STATUS: ✓ DETERMINISTIC, INTEGER-HASH-BASED, GPU/CPU PARITY CONFIRMED

Key Files:
  - src/terrain/VegPlacement.js: hash3(seed,ix,iz), rand(h,k)
  - src/terrain/PlanetFrame.js: groundHeightLocal(x,z) wrapper
  - mapspinner ^0.1.201: createHeightSampler()

Mechanism:
  - hash3() uses Math.imul + >>>0 (bitwise ops only)
  - No Math.random, Date, Math.sin -> deterministic every JS engine
  - rand(h,k) derives 9 independent salt-key streams from one uint32 hash
  - Both client (Vegetation.js) and server (VegPhysics.js) call same chain

Curvature Drop (PlanetFrame):
  - Formula: drop = r2 / radius / ((sqrt(1+s)+1)*sqrt(1+s))
  - EXACTLY 0 at origin (0,0), numerically stable far from origin
  - Avoids catastrophic cancellation of algebraic form (R+h)*dot - (R+anchorHeight)
  - Verified: frame.groundHeightLocal(0,0) === 0.000000 (exact)

Relief Scaling Integration:
  - mapspinner sampler.heightAt() returns relief-scaled metres (internal)
  - PlanetFrame applies NO additional scaling (would double-scale)
  - reliefScale baked into sampler results before PlanetFrame receives them
  - VegPlacement gates use reliefScale to scale WATER_MARGIN threshold

GPU/CPU Parity (mapspinner):
  - AGENTS.md caveat: prior parity gap 4.3m → 1.3m (uint32 lattice hash shipped)
  - Full 0m needed: shared baked heightfield (deferred, blocked by headless authority)
  - Current: ~1.3m divergence acceptable for placement purposes

Witness Tests: PASS
  - hash3 deterministic on 5 test seeds: ✓ 5/5
  - rand produces [0,1) values with distinct salt keys: ✓ 9/9 keys
  - groundHeightLocal(0,0) exactly 0: ✓
  - Curvature drop grows non-linearly: ✓ (0.0008m @ 100m, 0.0031m @ 200m)

## GATE MECHANICS: ORDER OF OPERATIONS

VegPlacement.classify() (line 148-179):

1. CHEAP REJECTS FIRST (before height sample):
   - dirToClimate sample: temp, humidity, erosion, seaBias
   - seaBias < -2 → reject (ocean basin)
   - baseDensity * coin >= coin → reject (fails density ceiling)
   ✓ This is the DOMINANT cost avoidance

2. THEN height sample (line 168):
   - frame.groundHeightLocal(x,z) - the SINGLE expensive sample
   - NaN guard (line 169)
   - WATER_MARGIN relief-scaled gate (line 175)
   - TREELINE elevation fade (line 176-179)

3. FINALLY slope samples (4x groundHeightLocal, line 184-189):
   - Central-difference gradient calculation
   - Slope rejection if grad > SLOPE_MAX
   - Normal calculation for slope-tilt quaternion

Result: OPTIMAL gate ordering minimizes sampling cost.
