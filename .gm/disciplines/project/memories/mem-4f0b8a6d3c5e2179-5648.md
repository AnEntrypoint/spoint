Deep-detail tier for AGENTS.md "Fire", "Planet-wide multiplayer" and "Chart re-anchor". AGENTS.md keeps the rule, the constant and the script name; this memo keeps the tables, the budgets and the witness scenarios.

Fire kernel
- Integer-only kernel `fireKernel.js`; decisions from `hash(seed, step, face, I, J)`; no float, `Math.random` or `Date.now`. Cells are 2x2 veg placement cells (8 m); step boundaries are absolute ticks.
- `ctx.navCostAt(x,z)` returns 8 burning / 2 charred. `fire.sightBlocked` and `ctx.canSee` cost 4-10 us per ray; `canSee` is gated by smoke through `_fireNavByRuntime` at depth >= smokeBlockDepth (`eyeHeightM` 1.6).
- Fire wind: the weather vector is the base, the `hash(seed, step)` field (`fireWind.js`) the gust; summed into one vector clamped to +-16 per axis. Keyframe `snapshot().wind` carries the BASE only — the gust is a pure function of seed and step, so a peer rebuilds it.
- Per-cell initial fuel is not recomputable in the integer kernel (`classify()`, `VegPlacement.js:170-234`). Any per-tile array added to `snapshot()`/`restore()` must join `TILE_ARRAYS` (`fireKeyframe.js`) with a VERSION bump (now 6); a mirror left on 5 diverges.
- A tampered keyframe is rejected at DECODE with a named `[fireKeyframe]` error and every read is bounds-checked. `G` is the ignition step mod 256, not an age. `slot = slot*64 + (J&7)*8 + (I&7)`. IGNITE_AREA is kind 5, radius <= 8 cells.

Fire witness scenarios (both run in the fire witness gate, `fire-witness-gate.mjs`)
- `fire-smoke-los-witness.mjs` measures the rule the smoke query ships: depth is summed over the metres of a ray that stay inside the plume (eyeHeightM 1.6 under a smokeHeightM top) and the verdict flips exactly once as smokeBlockDepth rises past that depth. It covers the in-face cell walk and the sampled path across a cube-face boundary, the exact eye-versus-plume-top boundary, a real `AppContext.canSee` that sees nothing until the fire burns and sees again once it is out, degenerate input at both gates, and cost per query (4-10 us over a burning front, a 135 km cross-face ray bounded by the 512-sample cap).
- `fire-wind-coupling-witness.mjs` recomputes the gust field independently on every step and checks that the fire's wind equals base+gust clamped to +-16, that a wire WIND event moves the base without losing the gust, that ServerWeather's clamped vector is the base, that a mirror and a late keyframe joiner land on the same wind and checksum, and that degenerate wind specs are refused.

Cluster assignment (`src/shared/clusterAssignment.js`)
- One server world per cluster, each its own flat chart. Assignment is pure, deterministic, hysteretic, antipodal-safe, 2-4 Hz. `resolveClusterConfig` refuses a link below the relevance ring or the longest weapon range.
- Collider rings (`ColliderStreamer.js`): `DEFAULT_MAX_CENTERS = 192` for BOTH trunk and rock streamers (`1d8358bf`); rings are per connected player, never the centroid. `classifyRings`' per-cluster quota resets every pass and is first-fill, not a guarantee; `evictOverCap` removes farthest-first.
- Boot ring is placement-generation-bound: 2.242 ms/chunk trunk, 0.883 ms/chunk rock, against `COMPUTE_BUDGET_MS` 2.5 ms.

Chart re-anchor
- Chart-local server holders migrate through `src/sdk/chartState/` (`attachServerChartMigrators(ctx, service)`; default off). A re-anchor is a change of basis, not a rotation: position, velocity and forward are invariant. CHART_REANCHOR is 0xc6; epoch u32 rides the snapshot header and input/fire/teleport messages.
- Flat chart + global gravity carries an intrinsic tilt term, fixed by shrinking the chart: `CHART_ANCHORS_PER_FACE = 32` (`chartAnchor.js`, `b6af3ff0`), worst cell angle 2.26 deg.
- `createChartAnchorLattice(radius, anchorsPerFace)`: 3/face = 54 anchors, worst cell-corner angle 21.235 deg; 6/face = 216 anchors, 11.309 deg. `CHART_REANCHOR_ANGLE_DEG` (28 / 14) must exceed the worst angle of the chosen lattice or the anchor thrashes.
- Exactly ONE chart per world (`setupTerrainStreaming` calls `createPlanetFrame` once), so two players at separation Delta sit at Delta/2, walkable iff `terrainTilt + Delta/2 <= 45 deg`.
- Cost: one re-anchor 0.17-0.45 ms; static migration ~22 us per flip. `ChartReanchorTerrain.js`: HeightfieldStreamer fields are REBUILT off-path (`prepareFields` 1.0-1.7 s CPU in 2 ms slices, `installPrepared` 1.2-2.1 ms); ColliderStreamer rings transform in place via `setBodyTransform`.
