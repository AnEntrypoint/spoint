project/moving-app-entity-needs-dynamic-bodytype: an app whose server code moves ctx.entity.position each tick (e.g. apps/combat-bot) must declare server.bodyType: 'dynamic'. spawnEntity defaults to 'static', and SnapshotEncoder skips bodyType==='static' entities in per-tick position encoding, so the entity silently never moves on clients. EditorHandlers PLACE_APP reads bodyType from the app def.
