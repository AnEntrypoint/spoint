Cube-sphere seamless circumnavigation is built by REANCHORING the single flat chart, not by radial gravity: Jolt exposes one global gravity vector, so world gravity stays [0,-18,0], character up stays +Y, and the 45 deg slope limit stays a flat-chart rule. Crossing a face boundary applies ONE rigid rotation to ALL state.

Landed (committed, witnessed by scripts/circumnavigate.mjs): src/shared/chartAnchor.js (createChartAnchorLattice, chartAnchorForDir, snapshotChart, createChartTransfer with vec/point/quat/look/tiltRad, reanchorChartFor, chartAnchorCellWorstAngleDeg) and frame.reanchor + frame.chartEpoch + the snapshot-copy frame.anchorDir getter in src/terrain/PlanetFrame.js.

NOT landed - runtime wiring, owned by whoever touches these files: (1) a protocol chart-epoch message so server and client agree the switch happened in one tick; (2) client applies frame.reanchor(dir) then createChartTransfer(from,to) to positions, velocities, yaw AND pitch via look() (a yaw-only carry discards induced pitch - measured 26.017 deg forward jump vs 0.000002 deg with look()), camera, floating origin, and in-flight snapshot/prediction state; (3) everything caching chart-local data must key on frame.chartEpoch - client/core/TerrainBackdrop.js:172,241, src/terrain/PlacementChart.js:26-28, src/shared/relocation.js:38,41; (4) scripts/bake-heightfield.mjs:35 and src/terrain/TerrainPhysics.js:69 validate baked artifacts against tcfg.anchorDir only and never chartEpoch, so a reanchor silently invalidates static trimesh bakes; (5) effective gravity rotates by the reanchor angle (measured induced pitch up to 41.4 deg).

Anchor lattice choice: anchorsPerFace=3 gives worst cell-corner angle 21.235 deg, and the 28 deg reanchor threshold sits above it, so a reanchor can never immediately re-trigger (anti-thrash invariant). Chunk identity is chart-independent (PlacementLattice.ringAroundDir takes no frame), so only chart-local placement/LOD data for the 19-24 loaded chunks changes; chartAnchorForDir is the pre-streaming primitive.
