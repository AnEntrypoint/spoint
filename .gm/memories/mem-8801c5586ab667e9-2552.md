DEFAULT_TERRAIN_HASH_VERSION=2 stays the shipped default: apps/world/tps-game.js declares carves [{center:[0,-20],radius:60,falloff:40}] and carves are v2-only (terrainCarvesOf returns [] for v1; height-cpu throws if carves are requested with v1). Measured on the real mapspinner/height-cpu sampler plus createPlanetFrame: v1 (carves dropped) gives anchorHeight 40.69, terrainBakeKey ed22dea5 and 8.31 m of relief across the aim_sillos arena footprint; v2 (carve honoured) gives anchorHeight 82.69, key 295d3adc and every spawn plus arena corner within -0.00..-0.03 m. Restoring v1 would silently delete a feature the shipped world declares. The v1-only consumers that break under v2: (a) the GPU patch collider -- packages/mapspinner/src/patch-baker.js, planet-orchestrator.js and shaders/terrain.glsl contain no hashVersion or carve code at all, so it can only express v1; src/terrain/TerrainPhysics.js now skips it for v!=1 and logs the reason instead of leaving gpuPatch null in silence. (b) scripts/bake-heightfield.mjs, whose in-page GLSL probe refused any hashVersion!=1; it now bakes v2 from the CPU height sampler, which is the exact v2 source (GPU/CPU v2 gap p50 1.3-1.5 cm, p99 7-9 cm) and needs no GPU or browser, while v1 still goes through the GLSL probe. (c) MinimapBake TAGGED_HASH_VERSIONS excluded the DEFAULT version from the artifact regex, so a .h2 request was not an artifact path at all; it is now TERRAIN_HASH_VERSIONS.join('|') and the tagged name comes from minimapTaggedBaseName so the '.minimap' suffix cannot drift from minimapBaseName. (d) client/core/RenderControls.js ?legacygl=1 forces hashVersion 1 (opt-in, unchanged). Client placement already agrees: client/core/TerrainBackdrop.js passes terrainHashVersionOf(cfg) and terrainCarvesOf(cfg) to createHeightSampler, identical inputs to planetSamplerOptsOf; measured client-vs-server-collider height gap worst 0.03 cm over 7 spawn/arena points, versus worst 18.25 m if the client is forced to v1 -- that counter-witness is what makes the parity number meaningful. The v2 tps-game.hf now shipped is N=257 extent 256 (1.00 m spacing, 134666 B, 16-bit 17x17 sectors, seed 1337, hashVersion 2, terrainKey 295d3adc): grid resolution chosen from the measured error curve -- whole grid mean 1.81 cm, p99 10.59 cm, max 25.15 cm; play area +/-64 m mean 2.0 mm, p95 10.0 mm, max 58.4 mm; boot coarse build 366 ms -> 53-62 ms and refine 662 ms -> 287-418 ms. The previous shipped .hf was N=33 extent 512 = 16 m spacing, which would have cost mean 50.73 cm, p95 159 cm, max 370 cm.
