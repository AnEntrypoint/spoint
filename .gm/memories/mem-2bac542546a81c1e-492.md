scripts/page-boot-witness.mjs fails an arm on any failed request, including net::ERR_ABORTED, which is a cancellation rather than a failure. tps-game aborts anim-lib.glb and apps/maps/<map>.glb.prog/model.progressive.glb on every load with 0 page errors and 0 console errors and a world that boots, so no arm can pass without --allow-failed-requests. Use --allow-console-error=<substring> for one named benign console message, and treat ERR_ABORTED as a known cancellation when reading a run.
