Terrain wet specular is displacement-masked puddles, not a uniform sheen. Cause of the old plastic look: tps-game weather is rain 0.6, so window.__wetness=0.6 and terrain.glsl added pow(dot(n,H),24)*wet*0.5 to EVERY land pixel on the smoothed geometric normal, ignoring material, micro-relief, sun intensity and host shadow -> one broad smooth glare column toward the sun (+29..+43 luma at sun 12deg). WebGPU patch-grid-render had no wet term at all. Design (both renderers): per-layer mask poolTex = 1 - smoothstep(lo[l], hi[l], disp) with disp = the splat albedo alpha already fetched (albA.a/albB.a), blended by bSharp like albedo (no seams at material edges); poolMask = mix(poolCover, poolTex, k=texMix*texFarFade) so far/untextured terrain gets the area-average coverage; pool = poolMask * (1 - smoothstep(slope0, slope1, slope)) * wetness; exponent mix(24, 256, pool); energy-normalised Blinn (e+8)/(8pi) * sunIrr (shadowed) plus sky reflection skyIrr/pi, both weighted by Schlick F on n; color = color*(1-F*pool) + that. Thresholds are measured: lo = p10, hi = p30 of each *-displacement.jpg (grass .455/.498, rock .408/.545, sand .275/.388, snow .404/.486); cover 0.18 = measured E[pool]; sd holds through mip 5, so no extra LOD fade. Params live in terrain-defaults.js (poolDispLo/Hi, poolCover, poolSpecExpRough/Sharp, poolSlope0/1) and resolve through src/pool-params.js (window.__poolDispLo etc overrides) for both gl-render.js uniforms (uPoolDispLo/Hi/Spec/Cover) and the WebGPU SurfParams buffer (32 + 64 bytes, written in updateFrame). Witness method: knob probes lo=-2/hi=-1 (none), lo=2/hi=3 (all), lo=0/hi=1 (linear 1-disp proxy); spec ratio by proxy decile rises monotonically from ~0 to 0.54 on both WebGL and WebGPU. The GLSL path is legacy pending TSL migration; the pooling function is small and should be ported as-is.
