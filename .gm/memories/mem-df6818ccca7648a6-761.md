project/world-persistence-worker-identity: singleplayer Worker world identity comes from INIT.worldName (app.js _clientConfig.worldName = ?world= stem when that world module loaded; BrowserServer forwards it; stall recovery spreads _clientConfig; host migration takes worldName from the host's full-worlddef announce, null if absent). WorkerEntry validates it with src/shared/worldName.js isWorldName and uses worldDef.name || INIT.worldName for ctx.worldName, appRuntime.worldName and worldDef._minimap, falling back to worldDefFingerprint only when neither exists (fingerprint discards the snapshot on any world-file edit or ?seed change). Snapshot is one IDB key 'world-snapshot' per origin, so switching worlds discards by world mismatch. Commit 7d29891a8e.
