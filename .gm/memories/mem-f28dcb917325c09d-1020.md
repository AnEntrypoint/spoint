scripts/lib/ holds five diagnostics, each one command, no flags needed for the common case. head-vs-worktree.mjs <paths...> prints per-path head= and worktree= content hashes and a verdict, so a gate failure over another lane's uncommitted edit is never misread as committed code. agent-report.mjs <task-id> [--blocks N] [--chars N] prints the last assistant text blocks of a multi-MB agent transcript. gm-dispatch.mjs <verb> [body-json] [--timeout-ms N] dispatches a gm spool verb with an atomic rename and fails loudly instead of silently. witness-audit.mjs scans scripts/*{witness,harness,gate}* for dead-gate shapes (verdict-cannot-fail, verdict-not-a-decision, bare-exit-zero, bare-flag-parses-to-true, nan-flag, self-comparison, dead-counter, flag-gated-arm); findings are candidate sites, confirm by running the file. ci-verdict.mjs <sha> prints the per-job verdict for that sha: exit 0 green, 1 red, 2 no run, 3 pending; it labels the frame-time job as queued-forever because no self-hosted GPU runner is online.
