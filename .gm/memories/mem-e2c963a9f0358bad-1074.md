project/witness-page-boot-failed-request-classification: page-boot-witness counts a request as failed only when it is a real failure; net::ERR_ABORTED is a cancellation of a speculative fetch, so it is bucketed as cancelled and printed as [request-cancelled] without failing the arm (scripts/page-boot-witness.mjs, CANCELLED_REQUEST_ERROR_TEXTS). Rationale: anim-lib.glb and model.progressive.glb are cancelled on every boot of a healthy page, so counting them meant no arm could pass without --allow-failed-requests and the flag stopped being a signal. What still fails an arm: HTTP >= 400. The one 404 left on a normal boot is the optional shader-manifest probe at client/app.js:745-749, which fetches /apps/world/<world>.shadermanifest.json and maps a non-ok response to null; only deathrun and tps-game have one committed, so every other world 404s on every boot while booting clean with 0 page errors. Witness with the classifier fixed and the manifest regenerated: tps-game --gl=none, failedRequests=0 cancelledRequests=2, RESULT: PASS with no --allow-failed-requests.
