spoint bake closure: a BAKE_TRANSFORMS entry need not declare the whole import closure of its obvious entry file. When the natural entry (here AppRuntime.js) transitively imports ~99 files, pick the narrowest module the cached transform actually reads as the closure ENTRY and declare the few modules the path reads as inputs, so declared >= closure(entries) holds without a pin that moves on nearly every commit (which would turn npm run check red each time). Verify a candidate input by reading the call site: a file in the closure that the path never references is not an input. Mutations prove the list: appending a line to a real input moves the SOURCE version, appending to a non-input leaves it unchanged.
