project/terrain-seed-single-source-terrainconfig: src/shared/terrainConfig.js is the only place terrain seed/config is resolved. resolveTerrainConfig = terrain entity config first, then worldDef.terrain. withTerrainSeed clones every seed home (worldDef.terrain, terrain entity config/custom, vegetation.seed), preserves shared references and never mutates the world module. minimapDescriptor builds the minimap base/center/extent. client ?seed, WorkerEntry, ServerAPI.loadWorld and the EditorHandlers reseed all use it. Minimap bakes live in src/sdk/MinimapBake.js: a worker_thread (~40 s CPU per bake), single-flight per base, and GET-missing /apps/world/<w>.<seed>.minimap.* bakes on demand (serial, cap 64). Terrain HEIGHT is seed-independent: mapspinner composeHeight never adds continentalBias, so the seed only changes climate/biome colour, the veg/rock/grass scatter and minimap colours. Witness seed changes via anchorField.sampleDir, not groundHeightLocal (53e0620a1e).
