project/app-teardown-releases-native-physics: HotReloadQueue runs the old app's teardown(ctx) before re-running setup on the SAME entity, so apps owning native physics must release it there (vehicle/tank destroyVehicle, destructible-box drain, softbody/fluid dispose). Without it createVehicleForEntity's already-has-vehicle guard leaves _vehicleId stale and createVehicle silently returns null forever.
