project/streaming-gltf-lod-worker-geometry-only-and-coarse-fallback: the LOD worker returns geometry only, so it registers a GLTFLoader plugin whose loadMaterial returns a placeholder MeshBasicMaterial. GLTFParser consults plugins before itself, so no texture (KTX2/webp) is ever fetched or decoded in the worker; this is why 'setKTX2Loader must be called before loading KTX2 textures' cannot recur there. Separately, model-pool Asset._loadCoarseClusterIndices turns a failed EP_cluster_lod coarse accessor into a console.error (URL + primitive + accessor), an asset.clusterLodFallbacks entry, and a LOD0-only attach via meshlet-codec lod0OnlyClusterLodExtras. It never swallows the error, and it never passes coarse=null with stream-1 LODs, which collapseFanTriangles rejects with a RangeError.
