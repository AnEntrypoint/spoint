project/perf-veg-lod-cells-and-weather-ground-grid-2026-10-05: (1) client/core/WebGPULodInstancer.js updateLOD buckets instances into 32 m cells (min/max centre box plus max bound radius). Each frame a cell is classified from eye distance (dmin/dmax) and an exact plane test of the radius-padded box (OUT/PART/IN). A cell with a uniform outcome (all beyond meshFar; or all frustum-out and all inside meshFar; or all frustum-in in one tier; shadow wanted uniform all or none) is applied once and skipped while its appliedKey is unchanged; otherwise it is evaluated per instance with the old logic. A cell recomputes tiers when cell.tierEpoch != eyeEpoch (eye moved >= 0.5 m since it last evaluated), so a cell skipped while frustum-out refreshes tiers on re-entry. Invalidation: addInstances resets the touched cell and sets lodStale; setMeshFarDistance calls invalidateCells; teleports/rebases need nothing because keys derive from the current eye and frustum, never from the previous eye. Witness (scratch lod-equiv.mjs): 520 steps incl 40 teleports, spin, add batch, meshFar 150/500, removals, visibility toggles, 0 pool-membership mismatches vs the old full scan; 7500 instances walking and turning every frame: old 1500-2200 us/frame, new 120-320 us/frame.
