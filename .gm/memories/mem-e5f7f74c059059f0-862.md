`three/tsl` exports `modelViewProjection` (the MVP = cameraProjectionMatrix * modelViewMatrix), plus `modelViewMatrix`, `modelViewPosition`, `cameraProjectionMatrix`, `cameraProjectionMatrixInverse`. It does NOT export `modelViewProjectionMatrix`. Using the Matrix-suffixed name is a hard module-resolution SyntaxError that boot-blocks the whole app, not a runtime undefined. Same class hit twice in this repo: `round` in `terrain-material-tsl.js` and `modelViewProjectionMatrix` in `packages/streaming-gltf/src/octahedral-impostor-capture-tsl.js`. Verify a TSL import name against the real export list before writing it: `import * as TSL from 'three/tsl'; Object.keys(TSL)` -- 638 names in the installed build, resolvable at node_modules/three/build/three.tsl.js. A full repo sweep is cheap (32 files, 471 named imports) and worth re-running after any TSL port.
