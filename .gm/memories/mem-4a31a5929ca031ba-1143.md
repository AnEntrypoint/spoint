scripts/bake-heightfield.mjs for hashVersion>=2 samples frame.groundHeightLocal from a frame built with offsetY 0, because TerrainPhysics adds offsetY to baked.heightAtLocal itself; folding offsetY into the bake would double it (a step of exactly offsetY at the artifact boundary). --world is mandatory now (it decides hashVersion, carves, terrainKey), --bits must be 8 or 16 (loader and codec read q as Uint8Array/Uint16Array; any other width wraps). Re-baking apps/world/tps-game.hf with --world tps-game --extent 256 --res 1 --sector 16 --bits 16 reproduces the shipped file byte-for-byte. .hf is served public,max-age=86400,immutable (StaticHandler CONTENT_HASHED_EXTENSIONS), so a warm browser profile keeps the old v1 bytes and logs 'ignoring baked heightfield' until cache-busted: use a fresh profile when witnessing. minimapTaggedBaseName(.h2) is a redundant alias of the untagged default-version artifact (same content, nothing references it); it exists so a literal .h2 request is accepted and refreshed. onDemandBakes entries are deleted on settle so staleness is re-checked per request and the cap bounds concurrency, not lifetime.
