Confirmed 2026-10-02: v2 terrain has no fast collider and no bake path, and it is NOT a forgotten parameter. `packages/mapspinner/src/patch-baker.js:77-93` reads only radius/reliefScale/seed/erosion and forwards to `initMapspinnerPlanet` imported from `./planet-orchestrator.js` (line 89) -- the legacy GLSL orchestrator. `planet-orchestrator.js`, `gl-render.js` and `shaders/terrain.glsl` contain zero occurrences of hashVersion or carves. Only `height-cpu.js` knows them, and it enforces that carves require v2 (throws if carves are requested with hashVersion 1). So giving v2 a fast collider means either a v2/carves variant of the legacy GLSL pipeline or moving the bake onto the TSL path -- a subsystem row, not a pass-through. Consequence with DEFAULT_TERRAIN_HASH_VERSION=2: the default world has neither the baked .hf nor the GPU-patch collider, so physics falls back to solveSurfaceY (16 x sampler.heightAt per candidate).
