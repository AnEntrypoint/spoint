project/jolt-value-getters-are-static-temps-never-destroy: jolt-physics [Value] Vec3 getters (CharacterVirtual.GetGroundVelocity, GetGroundNormal, GetLinearVelocity, and body GetAngularVelocity) return the SAME static per-method pointer on every call (probe via J.getPointer: identical ptr across calls). J.destroy() on one frees static memory; it can survive for a long time, then trap with 'memory access out of bounds' as soon as another getter is used in the same update (live: adding GetGroundNormal in CharacterManager.update made the existing destroy(GetGroundVelocity()) crash the server tick). Read the components and never destroy these; src/physics/CharacterManager.js had four such destroys, removed.
