project/fire-keyframe-tile-arrays-must-mirror-snapshot: adding a per-tile array to fireKernel snapshot()/restore() also requires adding it to TILE_ARRAYS in src/shared/fire/fireKeyframe.js AND bumping that file's VERSION, or a decoded keyframe hands restore() an undefined field. Measured: interiorLo/interiorHi were added to snapshot/restore for the interior memo but not to the wire, so fire-witness section 11 crashed with TypeError: Cannot convert undefined or null to object at fireKernel restore (interiorLo.set(s.interiorLo)) the moment a late joiner adopted a keyframe. Fixed by extending TILE_ARRAYS (version 3 -> 4); the header carries an FNV-1a checksum and declared length, so a version bump is the only way an old payload is rejected rather than misparsed. The encoder also derives a cell's pristine/scar code from fuel === classFuel[cls], so any new per-cell quantity has to be considered there too.
