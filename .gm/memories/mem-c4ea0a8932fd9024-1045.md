Perf A/B measurement on this machine cannot run concurrently with other agents' work. Measured 2026-10-02 with ~8 agents in flight: idle probes came back gpu3d 1/82/89/94/99, cpu 73-97, chrome 31-54, and CDP Input.dispatchKeyEvent hung past 25 s, killing two runs mid-walk. The load was self-inflicted (our own builds, browser sessions and checks), not the external train project. Consequences: (1) grant perf an EXCLUSIVE quiet window with every other agent held to zero CPU rather than letting it measure in parallel; (2) require the idle probe before AND after each run and discard any run whose after-probe shows load; (3) never average across bundles -- a third run rebuilt by another agent between the pair (127 GL draws, 8.6 ms shadow vs 108.8/3.911) is incomparable and was correctly flagged rather than averaged. Panel is 144 Hz, so p50 27.7-27.8 ms is 144/4 and p50 13.9 ms is 144/2 -- vsync divisors, not headroom; never read those as the machine's frame budget.
