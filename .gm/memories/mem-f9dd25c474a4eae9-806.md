project/bakecodeversion-input-list-must-exclude-the-pin-file: a BAKE_INPUTS_* list in src/static/BakeCodeVersion.js may not contain src/shared/cacheCodeVersions.js, because that file holds the pinned version value that bakeCodeVersion() computes over the list. Including it makes the hash self-referential: the value written into the file is a hash of a file containing that value, so scripts/check-cache-keys.mjs can never report a match and every lane fails. Keep the pinned marker file out of every hashed input list and exclude it from the closure-completeness check instead, which is what PIN_REL in scripts/check-cache-keys.mjs is for (SELF_REL already excludes BakeCodeVersion.js). The marker gate at the top of main() is what enforces the pin, and it prints the exact value to paste when it drifts.
