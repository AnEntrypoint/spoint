A `taskkill /IM chrome.exe` (or any kill by process image name) kills every browser on the machine, including CDP sessions, measurement runs and parity captures owned by other concurrent sessions. On 2026-10-06 a design-session subagent did exactly this and silently contaminated or killed runs in the spoint session sharing the box. Cleanup must target only processes whose command line carries this session's own profile path or an equivalent session-unique marker. When a browser run of yours dies for no visible reason, or an arm comes back suspiciously clean, suspect a machine-wide kill before suspecting the code, and re-take the arm.
