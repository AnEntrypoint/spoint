project/ses-evaluator-fails-closed-no-proxy-tier: src/sdk/SESCompartmentEvaluator.js is the only untrusted-app evaluator (consumer: AppLoader.loadUntrustedApp). If import('ses')/lockdown fails it throws SandboxUnavailableError (code SANDBOX_UNAVAILABLE) instead of evaluating; the old new-Function proxy tier (SandboxEvaluator.js) was deleted because it leaked real process.env/fetch/setTimeout and ({}).constructor.constructor('return process'). lockdown runs once per process via a module-level settlement and tolerates SES_ALREADY_LOCKED_DOWN, so a second evaluator instance or a foreign lockdown does not fail. ses is an optionalDependency needing @endo/cache-map, env-options, immutable-arraybuffer; a partial install without them makes import('ses') throw. First-party apps (apps/ dirs, trustedApps included) never touch this path: AppLoader.loadApp imports them directly.
