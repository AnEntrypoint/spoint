project/perf-witness-serves-stale-prebuilt-bundle: MEASURED 2026-10-02. The dev server serves PREBUILT BUNDLE from dist/client/app.js, and an arm that runs two hours after that build measures the old code while reporting the current sha -- ww-ww-fix.log line 3 shows 'serving PREBUILT BUNDLE from dist/client/app.js (built 2026-10-02T15:37:43.991Z)' against '[identity] sha=53b6a55b' for an arm that ran 17:37:44-17:53:45. The consequence was a false regression: the weather witness reported rain splash placement off the true ground by absMedian 0.165 m and absMax 1.485 m, and the current source cannot produce that because it resamples ground height exactly at impact inside GROUND_RESAMPLE_BAND_M=4 m (snow 2.0 m) before placing the splash. It is the same class as deviation.build-cache-no-code-version-key: an artifact keyed by its input cannot know the transform changed, and a bundle in dist/ is keyed by nothing at all. Every perf or browser arm must rebuild first and must log the bundle build timestamp into the arm's own JSON, refusing to record an arm whose bundle predates the newest source file, so a stale-bundle arm can never again be mistaken for a measurement.
