project/witness-scripts-must-assert-and-exit-nonzero: a witness script that prints its measurements without asserting them passes silently on a broken kernel. Measured on the fire lane: scripts/fire-tile-reclaim-witness.mjs and scripts/fire-kernel-cost-witness.mjs printed every number (live tiles after each fire, rewind checksums, heap deltas) but never set process.exitCode, so forcing tryReclaim to always decline or making checksum() return a constant left both scripts exiting 0. Fix shape: a local expect(ok, line) that increments a failure count plus a trailing `if (failures > 0) process.exitCode = 1`, with one check per measurement the script already prints, then prove it by mutation - inject the break, watch it fail, revert, re-run clean. The check that matters most is the one that makes the comparison non-vacuous: assert the recorded values are not all identical and that the rewind window actually contains a snapshot tick, otherwise a constant checksum satisfies every equality in the script.
