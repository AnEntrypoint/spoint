On scripts/peer-profile-harness.mjs the rollback rate is not a link measure: the scripted input changes six times per 2.4 s (~2.5/s), so rollbacks/s saturates at that rate and reads 0.5 / 2.9 / 2.9 / 2.7 at 0/0/0, 25/5/1, 50/10/2, 100/20/3. Average and max rollback depth are what track the link (1.3/1.8/3.8/6.7 avg, 3/6/10/12 max), maxRollbackTicks is reached at 100/20/3, and stalls and sub-target sim rate appear only there. Quoting a rollback rate from this harness without saying the input script caps it is a false measurement.
