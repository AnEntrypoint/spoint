project/debugging-playbook-live-gl-instrumentation-2026-07-10: live GL-error and rendering-defect method for spoint. (1) Console-text disambiguation: the same GL error code from two call sites is separated by the text logged with it, not by the code. (2) Draw-call stack capture: capture the stack at the draw, not at the error callback. (3) Trust live GL state over the JS-side cache: query the context, never read three's cached state. (4) Flicker is isolated by pixel-sample toggle elimination (turn one term off, sample, compare) rather than by staring at frames. (5) Classify discrete-vs-noise before chasing: a defect that fires every frame is a different bug class from one that fires once in a hundred. Tools: window.__tpOverride, window.__passProbe. An out-of-band renderer.render inside a probe captures a black void and reads as a rendering failure that does not exist.
