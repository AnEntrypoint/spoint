scripts/perf-run.mjs draws/frame was not a draw count until 2026-10-02 (8f5214d164). It read renderer.info.render.calls, which three's WebGPU (renderers/common) renderer bumps ONCE PER SCENE RENDER (Renderer.js `this.info.render.calls++`) and never resets: `Info.reset()` is only called from three's own `Animation` helper (common/Animation.js), and spoint drives its own rAF loop, so the counter ramps from 0 to max across a whole run. Witnessed signature on two 120 s arms: avg/max = 0.512 and 0.515, p95/max = 0.948, max/frames = 3.81 and 3.84 (= scene renders per frame, not draws). Draws per frame is now the per-frame DELTA of info.render.drawCalls (WebGL falls back to render.calls, which WebGLInfo increments per draw and WebGLRenderer resets per render). Same delta treatment for triangles. WebGPU has no GL context, so glCallsPerFrame/glDrawCallsPerFrame are 0 there by construction; the rig now wraps GPUDevice/GPUQueue/GPUCommandEncoder/GPURenderPassEncoder/GPUComputePassEncoder/GPURenderBundleEncoder/GPUCanvasContext prototypes and reports wgpuCallsPerFrame/wgpuDrawsPerFrame in the same 10 s window (arm window opens at t+3 s, closes at t+13 s).

GPU contamination on this box is not one chrome count. scripts/perf-run-gate.ps1 groups every chrome* process by walking ParentProcessId to its root, then buckets the group by the first --user-data-dir found in any member: perf=%TEMP%\spoint-cdp-* (this harness), gm=.*\.gm\browser-* (other agents' gm browser-verb sessions), train=dev.train, user=AppData\Local\Google\Chrome\ (the user's own browser, launched from explorer.exe, do not kill), other=everything else. The `Temp\puppeteer_dev_chrome_profile-*` instances are NOT orphaned: their parents are live `chrome-devtools-mcp` node.exe servers rooted at C:\dev\freddie (another project), parked on about:blank, so they inflate the process count but do no GPU work. Killing them kills another project's live MCP session. `ours` in the probe output now means the perf bucket only. data/perf-run/ is gitignored, so the probe lives at scripts/perf-run-gate.ps1 and perf-run.mjs reads it from scripts/ (inline fallback if absent).
