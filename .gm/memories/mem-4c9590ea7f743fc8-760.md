client/core/QualityGovernor.js drives only GOVERNED_KNOBS (ssao, bloom, ssr, vegLeafOff, maxLevel, splitFactor) and throws at construction and at apply() if a driven key is in RESOLUTION_KEYS (dpr*, vdrs*, threeVdrs*, fsr1*, vdrsUpscaleFsr1*, halfResWater, bloomResolutionScale), so dynamic quality never writes devicePixelRatio, canvas size or render-target size: no pixel doubling. resolveTier() takes min(booted, tier), so a low-tier preset is never pushed to more work than it booted with. QUALITY_TIERS tier 0 and tier 1 are byte-identical ({maxLevel:11, splitFactor:0.25, vegLeafOff:false}), so the ladder is monotone non-increasing, not strictly decreasing. Governor is live only when RenderControls qualityGovernor===true and qualityGovernorOff!==true.
