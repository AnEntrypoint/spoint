project/heap-delta-measurements-need-forced-gc: a process.memoryUsage().heapUsed delta measures uncollected garbage unless gc is forced first, and it will contradict itself. Measured in scripts/fire-kernel-cost-witness.mjs: the same takeDelta+release loop reported 1 MB retained on one run and 40 MB on another, and a first draft claimed 'the pool stops growing' from 5.10 MB then 5.08 MB across two consecutive batches - an artifact, not a finding. Correct shape: run node --expose-gc, take gc(); gc(); process.memoryUsage().heapUsed, warm the loop once before sampling, and report null when globalThis.gc is absent instead of printing a number; with that, the delta pool measures ~16.8 KB retained over the first 5000 cycles and 16 B over the next 5000.
