project/app-module-entry-blob-deps-http: client/AppModuleSystem.js turns only the app entry string into a blob: module. Its ./ and / static specifiers are rewritten to absolute URLs anchored at /apps/<name>/index.js, and deps load as normal http modules. A blob: URL has no hierarchical base, so any import inside a blobbed dep that the text rewrite misses fails to resolve (game-fsm's runtime-concatenated xstate path did). Bare specifiers go through the document importmap, which carries '@spoint/ecs' -> /node_modules/@spoint/ecs/src/index.js. Shared _lib deps are one instance per realm, as on Node AppLoader. Editing a nested dep needs a page reload to reach the client. Server EventBus handlers receive {channel,data,meta}, so read event.data; app client code gets the shared engineCtx (no bus/config) and must use onEvent/onFrame.
