project/streaming-gltf-spatial-split-tool: packages/streaming-gltf/tools/spatial-split.mjs splits a whole-map GLB into an XZ grid of tile GLBs (Y unsplit) by world-space triangle centroid, never cutting a triangle: a prim in one cell moves whole via copyToDocument, a straddling prim is rebuilt per cell as a compact-remapped triangle subset. Each tile is then run through bakeCluster, and a manifest records per-tile world AABB, tri/vert counts and provenance. Runtime screen-space-error tile prioritisation is NOT implemented. gltf-transform gotchas it works around: setMaterial across documents throws 'Cannot connect disconnected graphs' (copy the material with copyToDocument first); copyToDocument drags in source Buffers so a tile can end up with 2+ buffers, which GLB forbids (_flattenToSingleBuffer repoints accessors and disposes the extras).
