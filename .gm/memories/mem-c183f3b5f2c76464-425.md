project/snapshot-slot-release-window-vs-jitterbuffer: src/client/SnapshotProcessor.js SNAPSHOT_RELEASE_WINDOW (96) recycles the pooled player/entity slots of the oldest produced snapshot. It must stay above JitterBuffer maxSize (default 64, src/client/JitterBuffer.js), else a slot is reused while the buffer still interpolates that snapshot (corrupted remote players). Raising maxSize via config requires raising the window.
