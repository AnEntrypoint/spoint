project/streaming-gltf-lod-worker-module-remap: packages/streaming-gltf/src/lod-worker.js is a module worker. ModelPool passes it import.meta.resolve URLs (three, three/addons GLTFLoader, meshopt decoder, plus the package draco-loader) as query params, because workers ignore the page importmap (Chrome had not shipped worker importmaps as of 2026-09). worker-module-remap.js rewrites only the exact bare 'three' and recursively blobs relative imports. Its specifier regex is anchored at line start or ';' so JSDoc '* @three_import import ... from' lines in three addons never match. Remapping a 'three/addons/' prefix would match BufferGeometryUtils' self-referencing JSDoc and trip the cycle check. Never reintroduce esm.sh or a pinned CDN three there: it skews the worker's three version from the page's.
