project/componentpool-f64-for-epoch-and-config: ComponentPool columns holding Date.now() epochs (health.js lastHitAt) or designer config decimals read every step (steering.js speed/arriveRadius/yOffset) must be 'f64'. f32's ~7 digits truncates epochs by tens of seconds (breaks invulnMs i-frames) and perturbs config ~1e-8 per read (live-diffed compounding position drift). f32 only for integer-range values (hp/max/alive).
