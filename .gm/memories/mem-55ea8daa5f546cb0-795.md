project/bundler-sideeffects-list-drops-side-effect-only-imports: package.json declares sideEffects: ["src/protocol/MessageTypes.js", "client/core/Relocation.js"], so esbuild tree-shakes any side-effect-only import ('import ./core/X.js') of a file not on that list; source served unbundled works but dist/client/app.js silently lacks the module (window.__spoint was undefined, input loop threw 2344 page errors). Any new module that installs globals at import must be added to package.json sideEffects, and must be witnessed against the BUILT bundle (node scripts/bundle-client.mjs, fresh gm session id, ?v=<ts>) not only unbundled source. Also: the deployed gm runner has no `session close-all` (syntax error and it launches a fresh browser): close sessions one by one with `session close <id>`.
