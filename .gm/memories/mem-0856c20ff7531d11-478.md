Node delivers its own process deprecation warnings (DEP0152 DEPxxxx) to console.error through the process warning handler, not straight to stderr. Any witness that overrides console.error, tallies it and gates on an error count of zero must classify lines matching a leading (node:PID) [DEPnnnn] marker into their own bucket, or a Node upgrade turns a clean run into a spurious failure. Found in scripts/planet-multiplayer-harness.mjs, which now counts them as nodeDeprecations.
