gm's git_diff verb resolves the repository from the daemon process cwd, not from the dispatch's project root, so a dispatch that carries only a body fails with 'warning: Not a git repository. Use --no-index to compare two paths outside a working tree'. Passing cwd: "C:/dev/spoint" at the MCP dispatch level fixes it immediately. git_commit and git_push resolve correctly without it, so the bug is specific to git_diff. It also rejects a plural paths list; use path (singular).
