project/tsl-webgpu-perf-parity-2026-09-30: TSL renderer made faster than legacy on AMD and at parity on NVIDIA. Measured causes and fixes, same-page A/B with WebGPU timestamp queries (?gputime=1 sets trackTimestamp; costs ~20% fps, so fps is measured without it) and EXT_disjoint_timer per render-graph node via RenderGraph.setProfileHook: (1) DynamicDrawUsage full re-uploads (see webgpu-dynamicdrawusage-reuploads-every-render). (2) WebGPU vegetation drew every tree as mesh LOD at all distances with no culling (30M tris, 55 ms GPU): WebGPULodInstancer now does per-instance bounding-sphere frustum culling, a far mesh cutoff (setMeshFarDistance = FAR_LOD_SWAP) and the WebGPU shared impostor tier is baked with a TSL MRT capture material (streaming-gltf makeImpostorCaptureMaterialTSL; render target textures must be named output/normalDepth for mrt()); per-frame LOD loop over a Map (3.5 ms) replaced by a dense array gated on 0.5 m movement or a view-matrix change; empty pools hidden; the shadow-only pool lives on layer SHADOW_CASTER_ONLY_LAYER (30) which ShadowPipeline enables on WebGPU shadow cameras (three ShadowNode keeps a shadow camera mask that has bits beyond layer 0) so the main pass skips it. Veg mesh instances in view now match legacy InstancedMesh2 (14/22/71 vs 13/24/64 per tier at forest). (3) TSL terrain renderOrder was -10 so its heavy fragment shader shaded pixels later covered by the silo walls: renderOrder 10 (after opaque occluders) cut spawn GPU 8.0 -> 4.2 ms. (4) TSL terrain used GRID 16 and splitFactor*0.35; legacy uses TD.gridMeshSize 9 and TD.splitFactor with no LOD_LEAN: now identical quad sets (143 quads, same level histogram at spawn). (5) surfaceSplat sampled 24 array-texture taps per pixel unconditionally; now legacy-style If branches (skip layer B when wB<=0.02, far tap when octFarFade==0, normals when texFade==0) with textureGrad and derivatives taken before any branch (WGSL needs uniform control flow for implicit-derivative sampling); FS cost ~4 -> ~3 ms. (6) atmosphere LUT bake (~2 s), HPF anchor bake (~0.6 s) and surface-texture decode ran on the main thread in planet-tsl: now module workers (atmosphere-lut-job.js, tsl/hpf-bake-worker.js, surface-texture-worker.js via worker-job.js) with sync fallback; longest startup long task 1174 -> ~400 ms during planet init. (7) planet-tsl skips the quadtree when the camera moved < max(1 m, alt*5e-5) and forward is unchanged (legacy frame cache). Remaining gap: three WebGPURenderer per-object CPU cost (~30 us/draw, 82-128 veg draws) keeps the WebGPU backend a little behind legacy in dense forest on NVIDIA; the WebGL2 backend of WebGPURenderer is the fastest TSL path on NVIDIA.
